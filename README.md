# Lumen Wear

Modern unisex street & casual clothing demo storefront.

- Brand: **Lumen Wear**
- Stack: Next.js 14 (static export) + Tailwind CSS
- Contact: contact@lumenwear.shop

```bash
npm install
npm run build   # outputs to out/
npm run dev
```

Based on the open-source [fashion-shopping-store](https://github.com/ghufran29/fashion-shopping-store) template, customized for Lumen Wear.
